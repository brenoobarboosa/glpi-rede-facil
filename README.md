# GLPI Demonstrativo — Rede Fácil

Protótipo acadêmico de um sistema de gerenciamento de serviços de TI, desenvolvido com inspiração na interface tradicional do GLPI e adaptado ao cenário da empresa Rede Fácil, localizada em Aracaju – SE.

O projeto busca demonstrar processos de atendimento de chamados, gerenciamento de ativos, registro de problemas e organização das atividades da equipe de Tecnologia da Informação.

## Objetivo do Projeto

Desenvolver um protótipo funcional para representar uma solução de gerenciamento de serviços de TI, permitindo visualizar e organizar atividades relacionadas ao suporte técnico e à governança de TI.

## Funcionalidades

- **Dashboard:** painel com indicadores e chamados recentes.
- **Gerenciamento de chamados:** cadastro, edição, filtragem e alteração de status.
- **Gerenciamento de ativos:** cadastro e remoção de equipamentos.
- **Gerenciamento de problemas:** registro de problemas e ações preventivas.
- **Equipe de TI:** visualização dos papéis e responsabilidades da equipe.
- **TI Verde:** registro e atualização de ações ambientais.

## Tecnologias Utilizadas

- HTML5 — estrutura das páginas.
- CSS3 — estilização e identidade visual.
- JavaScript — funcionalidades e interatividade.
- LocalStorage — armazenamento local dos dados no navegador.

## Como Executar

1. Faça o download ou clone este repositório.
2. Abra a pasta `rede_facil_glpi`.
3. Abra o arquivo `index.html` em um navegador.
4. Utilize as funcionalidades disponíveis no protótipo.

Não é necessário instalar servidor, banco de dados ou dependências adicionais.

## Conceitos de Governança de TI

O desenvolvimento do protótipo utiliza como referências conceituais:

- **ITIL 4:** fluxo de incidentes, requisições e gerenciamento de problemas.
- **COBIT:** responsabilidades, riscos e indicadores.
- **ISO 14001:** propostas de ações ambientais relacionadas à TI Verde.

## Observações

Este projeto é um protótipo acadêmico independente, inspirado no GLPI. Não corresponde ao software GLPI oficial nem a uma instalação real da plataforma.

Os dados iniciais são fictícios e demonstrativos, baseados em cenários relatados para o projeto. Não representam inventário, chamados, SLAs ou práticas confirmadas da Rede Fácil.
